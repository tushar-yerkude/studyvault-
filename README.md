# StudyVault 📚

A responsive, local-first student study dashboard built with vanilla HTML, CSS and JavaScript.

## Features
- Dashboard with progress statistics
- Add, complete and delete tasks
- Subject tracking
- 25-minute Pomodoro focus timer
- Dark mode
- LocalStorage persistence
- Responsive mobile layout
- No backend required

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Push the repository to GitHub and enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Tech
HTML • CSS • JavaScript • LocalStorage
